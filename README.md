# My-First-Videogame
A learning experience both in game development and Java. The objective is to create a passable side-scroller 2d shooter.

As of now, it only consists of a basic interface made through JavaFX.

It includes three types of enemies:
  - Grunts (Blue): they fly in a straight line
  - Chasers (Purple): they fly towards the Player Character
  - Shooters (Yellow): The fly in a straight line towards you, then once in position they fly up and down while shooting.

Controls:
  - WASD to move;
  - J to shoot.
